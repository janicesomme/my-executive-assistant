# Captured Learnings

Repository of ideas, templates, and insights from Mark Kashef, Nate B Jones, Nate Herk, Nick Saraev, and other sources you follow.

Use the **Content Organization** skill to add captures. Search by #tags when you need something.

---

## How to Capture

Copy this template when you find something worth keeping:

```
SOURCE: [Name]
DATE: [YYYY-MM-DD]
TOPIC: [Category]
TITLE: [What is this?]

DESCRIPTION:
[1-3 sentences. What is it?]

KEY IDEA:
[The core takeaway. What makes this useful?]

APPLICATION:
[How would you use this? Where does it fit in your work?]

URL/REFERENCE:
[Where did you find it? Link or citation]

TAGS:
[#lead-gen #content-creation #automation #teaching #sales #personal-brand #business-model #ai-concepts #tools]
```

---

## Categories

Organize by these topics as you capture:

- **Lead Gen** — Finding and capturing leads
- **Content Creation** — Writing, scripting, producing
- **Automation** — n8n, workflows, systems
- **Teaching** — Curriculum, explanation techniques, how to teach concepts
- **Sales** — Outreach, closing, positioning
- **Personal Brand** — Visibility, social, YouTube, positioning yourself
- **Business Model** — Revenue, pricing, products
- **AI Concepts** — Core AI ideas to teach others
- **Tools & Stack** — Vercel, Lovable, Supabase, etc.
