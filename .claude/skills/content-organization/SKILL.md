# Content Organization System

**Purpose:** Capture learnings, templates, and ideas from the people you follow (Mark Kashef, Nate B Jones, Nate Herk, Nick Saraev, etc.). Organize them so you can find them later instead of losing them in random Claude chats.

**Why it matters:** You consume content daily but lose great templates and ideas. This system prevents that.

**When to use:**
- When you encounter a great idea, template, or insight from your sources
- When researching for SKOOL curriculum or YouTube videos
- When building a system and want to reference past learnings
- When you think "Wait, didn't I see something about this?"

---

## Content Capture Template

When you find something worth keeping, capture it like this:

```
SOURCE: [Mark Kashef / Nate B Jones / Other]
DATE: [YYYY-MM-DD]
TOPIC: [One of the categories below]
TITLE: [What is this?]

DESCRIPTION:
[1-3 sentences. What is it?]

KEY IDEA:
[The core takeaway. What makes this useful?]

APPLICATION:
[How would you use this? Where does it fit in your work?]

URL/REFERENCE:
[Where did you find it? Link or citation]

TAGS:
[List relevant tags for easy search: e.g., #lead-gen #content-creation #automation #teaching #sales]
```

---

## Recommended Topics

Organize your captures by these categories:

- **Lead Gen** — Finding and capturing leads
- **Content Creation** — Writing, scripting, producing
- **Automation** — n8n, workflows, systems
- **Teaching** — Curriculum, explanation techniques, how to teach concepts
- **Sales** — Outreach, closing, positioning
- **Personal Brand** — Visibility, social, YouTube, positioning yourself
- **Business Model** — Revenue, pricing, products
- **AI Concepts** — Core AI ideas to teach others
- **Tools & Stack** — Vercel, Lovable, Supabase, etc.

## Storage

Store captured content in a reference file that grows over time:

**File:** @references/examples/captured-learnings.md (you'll create this)

Format: Append new captures to the bottom. Use topic headers to organize.

When the file gets long, break it into topic files:
- @references/examples/lead-gen-templates.md
- @references/examples/content-creation-techniques.md
- @references/examples/automation-patterns.md
- etc.

When you need something:

I'll search your reference files and find what you captured.

## Workflow

1. You see something great from Mark/Nate/etc.
2. Capture it using the template above
3. Add to @references/examples/captured-learnings.md
4. Tag it with relevant #topics
5. Later: "Search my learnings for [X]" and I pull it up

This prevents losing ideas and builds your personal knowledge base over time.
